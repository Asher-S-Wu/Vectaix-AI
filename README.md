# 花卷 · Huajuan

An agent workspace for planning, tool use, research, document delivery and media creation. Administrators manage model connections, shared skills through Skills CLI, and media services from `/admin`.

Model connections support Chat Completions, Anthropic Messages and Responses. Credentials are encrypted on the server. Users work with conversations and projects; enabled skills and model settings apply across the platform.

Built with Next.js, React and MongoDB. Deploy on Railway using the included Railpack configuration and a persistent storage volume.

See the [Chinese project guide](README_ZH.md) for setup, configuration and verification.
