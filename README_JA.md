# 花卷 · Huajuan

計画、ツールの実行、資料調査、文書作成を行う Agent ワークスペースです。管理者は `/admin` でモデル接続、Skills CLI による共有スキル、画像・音声サービスを管理します。

Chat Completions、Anthropic Messages、Responses の3種類のプロトコルに対応しています。認証情報はサーバーで暗号化して保存します。

Next.js、React、MongoDB を使用し、Railway の永続ストレージと Railpack 設定でデプロイします。

設定と検証手順は[中国語ガイド](README_ZH.md)をご覧ください。
